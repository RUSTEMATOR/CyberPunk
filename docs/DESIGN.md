# Night City Life — дизайн-документ v1

## 1. Суть

BitLife в Найт-Сити. Каждый игрок проживает жизнь наёмника, корпората или бандита неделя за неделей. Персонаж может умереть навсегда, и тогда игра продолжается за наследника. Мир помнит предыдущие жизни.

Источники механик:
- **Cyberpunk RED / 2077** — статы, проверки, человечность, импланты, канон города: районы, банды, фиксеры, корпорации.
- **CY_BORG** — случайная генерация персонажа по таблицам, стартовый долг, ресурс «Глюки», высокая летальность, нуарный тон.
- **BitLife** — структура жизни: меню разделов, ход по кнопке, случайные события с выбором, отношения, карьера, тюрьма, наследники.

Второй принцип: **логика мира важнее условностей видеоигры.** Если в 2077 что-то ограничено ради баланса интерфейса (один имплант на ОС, одна кибердека вместо Сандевистана, одно оружие в руке), а в мире это физически возможно, у нас это возможно. Всё, что можно скомбинировать, комбинируется, последствия на игроке. Баланс держат человечность, деньги и риск, а не искусственные запреты.

Третий принцип: **всё опционально, как в BitLife.** Можно прожить жизнь без единого боя, можно только воевать, можно мешать. Можно жить без имплантов вообще. Ни один путь не обязателен, и у каждого есть своё развитие, свои награды и свои трудности.

Главный принцип: **код считает, Claude рассказывает.** Числа, броски, исходы и смерть определяет движок. Claude получает готовый результат и превращает его в текст.

## 2. Рамки v1

- Закрытая группа 5–10 игроков, вся игра в одной группе Telegram, у каждого игрока одно окно-сообщение.
- Язык игры — русский, сленг из русской локализации 2077: чумба, эдди, нова, дельта, риппер, нетраннер, корпо.
- Канон Cyberpunk: игра идёт сквозь эпохи, от времени, когда хром только появлялся, к 2077 и дальше (раздел 9a). Имена, места, банды и корпорации канонные для своей эпохи.
- Вне скоупа v1: совместные заказы, полноценное PvP (кроме слива компромата), захват районов, генерация картинок на лету.

## 3. Где идёт игра и интерфейс

Вся игра идёт в одной группе Telegram. Бот работает только в группе, сохранённой через `/admin_setgroup`. В других чатах и в личке игровые команды отвечают отказом. Скрытых данных нет: всё, что есть в окне игрока, видят все участники группы. Скрытым остаётся только то, что скрыто механикой игры (тип кибертолерантности до скана).

### Окно игрока
- У каждого игрока одно **окно**: сообщение бота с текстом экрана и inline-кнопками. Все действия (меню, заказ, бой, магазин, события недели, создание персонажа) **редактируют это же сообщение**. Новых сообщений игровой процесс не создаёт.
- `/play` (и синоним `/menu`) открывает окно. Если у игрока уже есть окно, бот удаляет старое и отправляет новое внизу чата, чтобы оно не терялось в истории. Сама команда игрока удаляется.
- Кнопки окна работают только у владельца. Остальным нажатие показывает всплывающее «Это не твоё окно, чумба».
- Через 10 минут без нажатий окно **сворачивается**: текст заменяется строкой «<Имя> — окно закрыто. /play», кнопки убираются. Нажатие на кнопку устаревшего окна делает то же самое.
- Длина экрана не больше 3 500 символов (лимит Telegram — 4 096). Бой показывает только последние 3 раунда, более ранние сжимаются в одну строку итога. События недели показываются по одному на экран.
- **Кнопки под узкий телефон** (iPhone mini/SE): подпись влезает примерно в 24 знака на всю ширину, 11 — при двух в ряд, 7 — при трёх (`balance.ui.button_chars`). Ряд, где подпись не влезает, разбивается по одной кнопке в ряд; слишком длинная одиночная кнопка пишется в лог. Списки (заказы, каталоги, магазины, жильё, варианты событий) дают подробности в тексте нумерованным списком, а кнопки короткие: название, «1 · Кража» или просто номер.
- **Оформление** (решение владельца): иконки, полосы, цитаты и спойлеры идут только через `app/bot/ui/style.py`. Одна иконка в начале строки или кнопки, не внутри фраз. Шкалы с максимумом (здоровье, человечность, настроение, заряд, здоровье врагов) показываются полосой `▰▰▰▱▱`. Повествование (события, брифинги, итоги заказов, текст Claude, ночные новости) стоит в цитате; последствия — строками с иконками. Карта Мисти открывается спойлером. В бою старые ходы свёрнуты в раскрывающуюся цитату, последний ход виден сразу. Иконка в кнопке считается за два знака бюджета `button_chars`.
- **Иконки** лежат в `content/icons.yaml`: ключ, обычный эмодзи и необязательный `custom_emoji_id`. С id текст сообщений показывает премиум-эмодзи (`<tg-emoji>`), обычный эмодзи остаётся запасным; кнопки всегда с обычным эмодзи. Загрузчик проверяет, что есть все иконки, которые использует код, и аркан для каждой карты.
- **Кубики Telegram**: `/caliber`, `/race`, `/catfight` бросают 🎲 в чат, азарт (и переброс за глюк в азарте) крутит 🎰. Значение кубика переводится в прежний диапазон броска по квантилю (`engine/dice.py`: `roll_from_face`, `d10_from_face`), так что средние и смысл баланса сохраняются, а одно значение всегда даёт один результат. Результат показывается через `ui.dice_reveal_s` секунд, когда анимация закончилась; сообщение с кубиком временное. Если кубик не отправился, бросок делает генератор, как раньше.
- **Ввод текста** (имя персонажа, «Своё действие», разговор с NPC): окно пишет «Ответь сообщением», бот берёт следующее сообщение этого игрока в группе, удаляет его и обновляет окно. Кнопка «Отмена» выходит из ожидания.

### Самоочистка
- Команды игроков удаляются сразу после обработки.
- Временные ответы бота (ошибки, `/who`, `/legends`, `/graveyard`, подтверждения админ-команд) удаляются через 60 секунд.
- Лента города остаётся в чате дольше: ночные новости удаляются через 48 часов, сообщения о киберпсихах, MaxTac и арестах — через 24 часа. Некрологи не удаляются.
- Все сроки задаются в `balance.yaml` (раздел `ui`).
- Для удаления нужны права администратора группы с разрешением «Удаление сообщений». Без них игра работает, но мусор остаётся. Бот один раз предупреждает об этом при `/admin_setgroup`.

### Лимиты Telegram
Бот может отправить в группу не больше ~20 сообщений в минуту. Поэтому все отправки и правки идут через очередь на чат: не больше 15 операций в минуту, и если для одного окна в очереди несколько правок, отправляется только последняя. Игрок при быстрой серии нажатий видит итоговое состояние, а не каждый шаг.

### Лента города
В той же группе публикуются:
- ночные новости «Ночной эфир 54» раз в сутки по итогам действий игроков;
- некрологи;
- розыск NCPD (у кого розыск 4+);
- громкие события: киберпсих, налёт MaxTac, крупный заказ;
- ответы на `/who` (кто жив и где), `/legends` (топ по уличной репутации), `/graveyard` (кладбище).

## 4. Игровой цикл

### Время
- Время идёт **неделями**. Каждые 52 недели персонажу +1 год.
- Каждая неделя даёт **3 очка действий (ОД)**. Большинство действий стоит 1 ОД.
- Кнопка **«Прожить неделю»** закрывает неделю: зарплата, аренда, отложенные итоги событий, проценты и минимальный платёж по долгу, восстановление здоровья, спад розыска, 1–3 случайных события, сброс ОД.
- Лимит: не больше 7 недель в реальные сутки на игрока (настраивается).
- **Глобальный тик** раз в сутки в 03:00 по Киеву: ночные новости, остывание жары районов, случайные войны банд, курс монеты. Это только реальное время: канон, эпохи и доски заказов считаются по личной дате (раздел 9a).

### Главное меню (как в BitLife)
| Раздел | Что внутри |
|---|---|
| Профиль | статы, здоровье, настроение, деньги, долг, репутация, розыск, импланты |
| Заказы | фиксер своего района → 3 заказа → выбор подхода → исход |
| Работа | легальная карьера, «работать усерднее», уволиться |
| Активности | тренировка, учёба, бар, брейнданс, терапия, азарт, отдых |
| Отношения | семья, партнёр, друзья, контакты, дети |
| Имущество | жильё, транспорт, оружие, броня, переезд |
| Риппер | установка и снятие имплантов, скан кибертолерантности |
| Криминал | карманная кража, угон, ограбление, нападение |
| Переезд | сменить район (меняет фиксера, банды, события) |
| Прожить неделю | конец хода |

## 5. Персонаж

### Генерация (в стиле CY_BORG: всё случайно, игрок выбирает одно)
1. **Стартовый пресет** — стартовый набор: перекос статов, пара навыков, немного снаряжения, иногда карьера. Пресеты доступны все сразу (по эпохе): Обычный житель, Уличный стрелок, Ребёнок Сети, Гаражный мастер, Санитар, Делец, Уличный музыкант, Корпоративный стажёр, Патрульный-новичок, Кочевник, Послушник и другие. **Пресет — это не роль.** Роль появляется из того, как ты играешь (раздел 5b).
2. **Происхождение** (d10, по эпохе): уличный ребёнок Уотсона, сын корпората, кочевник из Бэдлендс, бывший член банды, ветеран корпоративной войны, беженец, выросший в мегабашне, сирота из приюта, бывший заключённый, ребёнок рипперов. Редкие происхождения пути без хрома: **послушник буддийского монастыря**, **ребёнок общины проповедника против имплантов** (раздел 7a).
3. **Стартовый долг** (d10): кому и сколько. Тигриные когти, риппер из Кабуки, банк, Maelstrom, мать-одиночка с пистолетом, корпорация и так далее. 3 000–8 000 эдди под 0,75% в неделю. Каждую неделю, если хватает эдди, автоматически списывается минимальный платёж: 2% долга, но не меньше 100 эдди. Средний стартовый долг на средней работе гасится за 1–2 года, и на жизнь остаётся. Коллектор приходит только после двух пропущенных минимальных платежей подряд (раздел 11).
4. **Черта, примета, одержимость** — по таблицам d20, только для нарратива.
5. **Возраст** 18–30, имя и фамилия из списков, семья (см. раздел 10).
6. **Кибертолерантность** — скрытый бросок (раздел 7).

### Статы (2–8 на старте, максимум 10)
| Стат | Значение |
|---|---|
| ТЕЛО | сила, здоровье, спасброски от смерти |
| РЕФЛ | стрельба, уклонение, вождение |
| ТЕХ | техника, крафт, медицина |
| ИНТ | взлом, учёба, карьера |
| ХЛАД | убеждение, давление, нервы |
| ЭМП | отношения; задаёт человечность |
| УДАЧА | пул очков: каждое очко даёт +1 к проверке, пул восполняется раз в неделю |

Распределение: шаблон роли (основные статы 6–7) плюс случайный разброс ±1.

### Навыки (0–10, на старте 0–6 по роли)
Стрельба (РЕФЛ), Ближний бой (ТЕЛО), Скрытность (РЕФЛ), Нетраннинг (ИНТ), Техника (ТЕХ), Медицина (ТЕХ), Убеждение (ХЛАД), Вождение (РЕФЛ).

Прокачка: действие «Тренировка/Учёба» даёт опыт навыку, а успешная проверка на заказе — +1 опыта. 10 опыта = +1 уровень (по мере роста навыка нужно больше).

### Шкалы
- **Здоровье** = 10 + 5 × ТЕЛО. Меньше половины — тяжёлое ранение, −2 ко всем проверкам.
- **Настроение** 0–100 (BitLife «Happiness»). Низкое настроение вызывает события срыва и зависимости от брейнданса.
- **Человечность** — см. раздел 7.
- **Три репутации**, у каждого пути своя:
  - **Уличная репутация** 0–50 — заказы, фиксеры, банды;
  - **Статус** 0–50 — карьера, деньги, связи наверху, жильё, корпоративные двери;
  - **Слава** 0–50 — фанаты, медиа, сцена, общественное мнение.
  Каждая открывает свои возможности, `/legends` показывает топ по каждой.
- **Розыск NCPD** 0–5, растёт от криминала, падает на 1 в неделю, если не было новых преступлений.
- **Глюки** 0–3 (из CY_BORG). Каждую неделю добавляется d4−1, но не выше 3. Глюк тратится на переброс любой проверки. Переброс спасброска от смерти глюком доступен один раз за жизнь.

## 5b. Роли растут из стиля игры
Роль не выбирается при создании, а **зарабатывается**. Как в BitLife: ты становишься тем, чем занимаешься.
- У каждой роли есть **сродство** (`role_affinity`). Его растят действия через шину событий: громкие заказы и победы в бою — Соло; взломы и быстрые взломы — Нетраннер; ремонт, сборка, крафт — Техник; лечение — Медтех; сделки, посредничество, связи — Фиксер; выступления — Рокербой; репортажи и съёмка — Медиа; корпоративная карьера — Корпорат; служба в NCPD — Коп; дорога, вождение, Бэдлендс — Кочевник. Плюс роли вне RED: Монах (обеты, медитация), Аферист (ненасильственный криминал), Торговец (бизнес и перепродажа).
- Сродство медленно остывает (процент в неделю), поэтому смена образа жизни меняет и роль.
- **Ранг роли** 0–10 считается из сродства. На рангах 2, 5 и 8 открываются **перки роли** — модификаторы в духе способностей RED: «Боевое чутьё» Соло, «Интерфейс» Нетраннера, «Мастер» Техника, «Медицина» Медтеха, «Оператор» Фиксера, «Харизма» Рокербоя, «Доверие» Медиа, «Команда» Корпората, «Подкрепление» Копа, «Своя тачка» Кочевника.
- **Основная роль** — с наибольшим сродством, **вторая** — следующая. Перки работают у всех ролей по их рангам, так что гибрид Соло-Медтех или Фиксер-Рокербой — нормальный билд.
- Роль показывается в профиле и в `/who`, события и фиксеры реагируют на основную роль.

## 5a. Пути и стиль игры
- **Бой не обязателен.** Боевые ситуации возникают только по выбору игрока: подход «громко» в заказе, криминал с насилием, карьера в NCPD или MaxTac, ответ на провокацию в событии. Если бой навязан (засада, катастрофа на заказе), у игрока есть небоевые варианты: заплатить, договориться, сбежать, сдаться, позвать помощь. **Они не гарантированы**: это проверки, и шанс зависит от того, с кем имеешь дело и в какой ситуации (раздел 6 «Выходы без боя»). Отбитые Maelstrom почти не берут денег и не слушают, NCPD охотно берёт взятки, киберпсиху всё равно.
- **У событий** с риском насилия всегда есть хотя бы один небоевой вариант (загрузчик это проверяет), но он может провалиться.
- **Небоевой путь** развивается через карьеру, учёбу, отношения, бизнес, сцену, медиа, торговлю, мелкий ненасильственный криминал (кражи, аферы, контрабанда). Растут Статус и Слава, открываются жильё, связи и свои ветки событий.
- **Боевой путь** — заказы, бой, хром, уличная репутация.
- **Смешанный** — любая комбинация. Билд (раздел 8) делается под путь, а не под бой.
- У каждого пути свои ежедневные задания (раздел 12a), свои топы и свои смерти: небоевой персонаж чаще умирает от старости, долгов, болезней и выгорания, чем от пули.

## 6. Проверки и бой

### Проверка (RED)
`стат + навык + d10 + модификаторы ≥ СЛ`
- d10 = 10 — критический успех: добавить ещё d10.
- d10 = 1 — критический провал: вычесть d10.

| СЛ | Сложность |
|---|---|
| 9 | простая |
| 13 | обычная |
| 15 | сложная |
| 17 | профессиональная |
| 21 | героическая |
| 24 | невероятная |

### Исход на 4 уровня
Нужен для заказов и событий:
- **Чисто**: прошли все проверки.
- **С осложнениями**: провалена одна проверка, или прошли, но с разницей меньше 2.
- **Провал**: провалено больше половины проверок.
- **Катастрофа**: критический провал на ключевой проверке.

### Бой (тиками)
Бой идёт **тиками**: 1 тик = 1 раунд, примерно 3 секунды. Карты нет.
- **Противники поштучно.** Опасность 1–5 задаёт размер пачки (1–5 врагов, кубик из `balance.yaml`) и параметры каждого: здоровье 6 + 4 × опасность, урон по таблице опасности.
- **Тик игрока.** Выбрать действие кнопкой: стрелять, ближний бой (летально или нелетально), укрыться, бежать, сдаться. Цель — конкретный враг. Отдельными бесплатными кнопками включаются активные импланты (ниже), если у них хватает заряда.
- **Попадание:** проверка Стрельбы или Ближнего боя против СЛ по опасности врага. Урон по оружию: пистолет 2d6, пистолет-пулемёт 2d6 (+1 попытка), дробовик 5d6 вблизи, винтовка 5d6, клинки-богомолы 3d6, руки-гориллы 3d6. Броня вычитает своё значение защиты.
- **Убийство и обезвреживание.** Враг с нулём здоровья после летальной атаки — **убийство**, после нелетальной (кулаки, руки-гориллы, приклад) — **обезвреживание**. Оба считаются для подзарядки имплантов.
- **Мораль.** Когда выбыла половина пачки, каждый оставшийся враг с шансом 30% в тик бежит. Сбежавший не даёт подзарядки.
- **Тик врагов.** Каждый живой враг атакует. Kerenzikov может сработать на попадание (ниже).
- **Конец боя:** все враги выбыли, игрок сбежал или сдался, или прошло 8 тиков — тогда подходит подкрепление, и игрок должен бежать или сдаться.

### Противники
**Противники играют по тем же правилам, что и игрок.** У врага такие же импланты из того же каталога, тот же заряд, те же пороги включения, досрочное выключение, подзарядка за убийства, быстрые взломы и Kerenzikov, который уводит его от твоей пули. В движке игрок и враг — один и тот же тип «боец», разница только в том, кто выбирает действие.
- **Архетипы** лежат в `enemies.yaml`: фракция (банда, корпорация, NCPD, MaxTac, киберпсих), опасность, здоровье, атака, защита, оружие, броня, список имплантов, быстрые взломы, поведение.
- **Пачка** собирается из архетипов фракции цели заказа: лидер на уровне опасности заказа, остальные ниже. У каждой фракции свой почерк: Maelstrom — тяжёлый хром и Берсерки, Тигриные когти — Сандевистаны и клинки, Voodoo Boys — нетраннеры, Animals — сила и руки-гориллы, Arasaka — дорогие гибкие модели, MaxTac — «Апогей» и Kerenzikov Boosted.
- **Поведение** (`ai` архетипа, правила в `balance.yaml`):
  - *громила*: включает всё, как только хватает заряда, никогда не выключает;
  - *тактик*: включает длительные импланты, когда его здоровье ниже 60% или у игрока работает свой; выключает досрочно, если заряд ниже 30% и игрок не угрожает; копит заряд;
  - *нетраннер*: держится сзади (защита +2), бьёт быстрыми взломами; первая цель — работающий имплант игрока (слив заряда, отключение);
  - *трус*: бежит при здоровье ниже 50%.
- **Что видно игроку.** Без сканера в оптике окно пишет «хром не опознан». Со сканером (`enemy_scan`) видны импланты врагов и их заряд. Поэтому оптика — часть билда, а не просто +1 к стрельбе.

### Здоровье 0 → спасбросок от смерти
`d10 < ТЕЛО` — выжил, лежишь при смерти. Каждый следующий спасбросок в той же схватке −1.
Перед смертью проверяется:
1. Подписка **Trauma Team**: Серебро даёт 50% на эвакуацию, Золото 80%, Платина 100%. Эвакуация стоит денег (влезть в долг можно).
2. Имплант **Второе сердце**: одно воскрешение, потом имплант сгорает.
3. Глюк: потратить глюк на переброс спасброска (раз в жизнь).

## 7. Человечность и кибертолерантность

- Стартовая человечность = ЭМП × 10.
- Каждый имплант снимает **ПЧ** (потерю человечности), умноженную на коэффициент кибертолерантности.
- Каждые 10 потерянной человечности: ЭМП −1.
- Человечность 0 → **киберпсихоз**. Это не мгновенная смерть, а эпизод (раздел 7b): срыв, охота MaxTac в ленте, бой. Дальше — смерть, побег или вербовка в MaxTac.

### Кибертолерантность (скрытый бросок d100 при создании)
| d100 | Тип | Множитель ПЧ |
|---|---|---|
| 01–10 | Хрупкий | ×1.5 |
| 11–75 | Обычный | ×1.0 |
| 76–95 | Устойчивый | ×0.6 |
| 96–99 | Железный | ×0.3 |
| 00 | **Смэшер** | ×0.1, открывает «Полную конверсию» |

- Тип скрыт. Риппер делает скан за 500 эдди. Виктор говорит правду, Фингерс иногда врёт.
- Смэшер может уйти в **полную конверсию**: тело заменяется целиком, ЭМП фиксируется на 1, но киберпсихоз невозможен. Отношения с семьёй разрушаются, а NPC боятся.
- **Терапия** (Активности, 1 ОД, 300 эдди) возвращает 2d6 человечности, но не выше максимума за вычетом установленных имплантов.
- Снятие импланта возвращает половину его ПЧ.

## 7b. Киберпсихоз и MaxTac
Как в каноне: MaxTac охотится на киберпсихов и сам набирает людей, которые были на краю или за краем.

**Эпизод киберпсихоза** (человечность 0):
1. Срыв: в ленту уходит пост «Киберпсих в <район>», окно игрока переходит в бой. Игрок играет срыв: вокруг пачка NCPD, через 2 тика прилетает MaxTac (опасность 5).
2. Выходы: прорваться и уйти (бой и побег), сдаться MaxTac (бросок по их нраву: шанс, что не дослушают), погибнуть.
3. Если ушёл — персонаж становится **беглым киберпсихом**: розыск 5 навсегда, охота MaxTac каждые несколько недель, обычная жизнь закрыта, пока не сдался или не поймали. Можно сдаться позже.
4. Если взяли живым — **выбор MaxTac**:
   - **Контракт MaxTac**: тебя стабилизируют, ставят **ингибитор** (имплант-поводок: нижний порог человечности 5, отказ от приказа = разряд и потеря здоровья), хром остаётся. Карьера `maxtac` со своими рангами, зарплатой и обязательными вызовами на охоту за киберпсихами раз в несколько недель. Уйти нельзя, пока не отслужил срок; дезертирство = снова беглый.
   - **Изолятор**: тюрьма-клиника на 26–52 недели, терапия возвращает человечность, часть хрома снимают. Выходишь живым, но с пустыми руками.
   - Смерть на месте, если MaxTac решил не рисковать.

**Шанс вербовки** выше у тех, кто для MaxTac ценен: тип кибертолерантности (Смэшер и Железный почти всегда), боевой ранг роли Соло или Копа, уличная репутация, отсутствие убийств гражданских. Шанс и пороги в `balance.yaml`.

**Обычный путь в MaxTac** тоже остаётся: карьера NCPD до ранга детектива и импланты не меньше чем на 20 ПЧ.

Служба в MaxTac — источник событий: охота на киберпсихов (бои опасности 4–5), иногда на тех, кого ты знал, включая персонажей других игроков, ушедших в беглые.

## 7a. Без хрома
Можно прожить жизнь вообще без имплантов: буддийский монах, член общины проповедника, который зовёт отказаться от хрома, или просто человек, у которого нет денег или желания. Это полноценный путь со своими плюсами и трудностями.

**Плюсы чистого тела** (пока не установлен ни один имплант, флаг `chrome_free`):
- киберпсихоз невозможен, человечность всегда полная, ЭМП не падает;
- **быстрые взломы почти не работают**: вражескому нетраннеру не за что зацепиться. Работают только взломы через окружение (с пометкой в `quickhacks.yaml`), и с большим штрафом;
- тело без хрома учится быстрее: опыт навыков выше (`balance.chrome_free`);
- бонусы к проверкам отношений, терапии и медитации; NCPD-сканеры не видят ничего подозрительного.

**Трудности:**
- нет бонусов имплантов, в бою против хромированных тяжело;
- часть карьер и заказов недоступна или сложнее (MaxTac, нетраннинг, боевые заказы высокого уровня);
- город не любит чистых: часть событий, где тебя презирают, обманывают или вербуют.

**Обеты** (для монахов и общины, необязательно для остальных): игрок принимает обет — «без хрома», «без насилия», «без брейнданса», «без лжи». Пока обет держится, растёт **серия** в неделях и бонусы (опыт, настроение, Слава в своей общине, отношения). Нарушил — серия сгорает, событие с последствиями, обет можно принять заново. Обеты лежат в `vows.yaml`.

**Активности пути:** медитация (настроение, человечность у тех, кто вернулся от хрома, снятие розыска как «залечь на дно»), боевые искусства (Ближний бой, нелетальные удары сильнее), служение общине (отношения, Слава, немного эдди).

Если чистый персонаж ставит имплант, флаг снимается навсегда для этой жизни, а снятие хрома его не возвращает.

### Активные импланты: заряд и тики
Боевые импланты работают не «раз в бой», а на **заряде** 0–100%, как в 2077. Заряд хранится у каждого установленного импланта и переносится между боями.

**Заряд — это топливо.** Пока длительный имплант работает, он сжигает 100 / N процентов за тик, где N — длительность на полном заряде. Включил на 40% — проработает 40% от полной длительности.

**Чем дороже модель, тем она гибче, а не просто сильнее:**
- **Порог включения** у каждой модели свой. Дешёвый Сандевистан включается только на полном заряде, «Апогей» — от 10%.
- **Досрочное выключение** есть только у дорогих моделей. Выключил — остаток заряда сохраняется для следующего тика или следующего боя. Дешёвая модель, включившись, выгорает до нуля.
- **Подзарядка за убийство и обезвреживание** работает всегда, даже пока имплант включён, и тогда продлевает его. «Апогей» в плотном бою почти не выключается.
- **Kerenzikov Boosted** можно поставить на «авто» или выключить и не тратить заряд на слабые попадания. Обычный Kerenzikov срабатывает на любом попадании.
- **Ракеты** тратят заряд за каждую ракету: одна ракета от 50%, залп по двум целям от 100%.

**Режимы:**
- *длительный* (Сандевистан, Берсерк): работает, пока не кончится заряд или пока его не выключили;
- *реактивный* (Kerenzikov): срабатывает сам, когда враг попадает по игроку, и тратит фиксированную часть заряда;
- *выстрел* (ракеты): списывает заряд за каждую цель.

**Подзарядка:** в бою + N% за тик, пока имплант не работает; + N% за каждое убийство и обезвреживание (всегда). Вне боя +50% за каждое потраченное ОД, полный заряд в конце недели.

**Перегрузка:** каждое включение при человечности 20 и ниже стоит 1 человечности.

Модели одного типа (`exclusive_group`) взаимоисключающие, разные типы сочетаются: Kerenzikov + Сандевистан + Берсерк + ракеты одновременно — законная сборка.

Цифры вдохновлены 2077 и подобраны под наш бой, все лежат в `cyberware.yaml`. Новые модели и импланты добавляются по тем же правилам: дорогое — гибкое.

**Сочетать можно всё.** Ограничений по слотам нет: любой хром ставится вместе с любым. Богомолы выходят из предплечья, ракетная установка сидит у кисти той же руки, а руки-гориллы дают силу тем же рукам. Kerenzikov, Сандевистан и Берсерк работают вместе. Кибердека ставится рядом со всем остальным. Чем рискует игрок — его человечность.

Запрещено только то, что физически невозможно:
- один и тот же имплант дважды;
- два импланта, которые заменяют один и тот же орган (`exclusive_group`): две пары оптики, две кибердеки. Установка новой вещи из группы — это замена: старая снимается по правилам снятия.
- имплант без нужной основы (`requires`): кибердека без нейропорта.

Колонка «Слот» в таблице — место на теле для описаний и для риппера, а не ограничение.

У каждого риппера своя цена и риск:
- **Виктор Вектор (Уотсон)** — нормальная цена, осложнений нет.
- **Фингерс (Вестбрук)** — −30% к цене, 20% шанс осложнения: +50% ПЧ или имплант сбоит.
- **Подпольный риппер в каждом районе** — −50% к цене, 35% шанс осложнения и шанс заражения.

### Модификаторы и билды
**Цель — максимально гибкий билд, боевой и небоевой.** Любой имплант (а также броня, оружие и черты характера) даёт набор **модификаторов** `mods`. Движок суммирует модификаторы всего, что стоит на персонаже, и применяет их везде, где они имеют смысл. Модификаторы одного вида складываются, общие потолки лежат в `balance.yaml`.

| Модификатор | Что делает |
|---|---|
| `stat.<СТАТ>` | +N к стату (УДАЧА — к размеру пула) |
| `skill.<навык>` | +N к проверкам навыка |
| `xp.<навык или all>` | +N% опыта навыка |
| `check.<контекст>` | +N к проверкам в контексте: combat, gig_loud, gig_quiet, gig_talk, gig_hack, crime, career, social, escape, heal |
| `hp_max`, `armor`, `damage_reduction` | здоровье, броня, снижение входящего урона |
| `melee_damage`, `ranged_damage` | +N к урону за попадание |
| `strength`, `flee`, `bleed` | проверки силы, побег, снижение урона от кровотечения |
| `hp_regen`, `mood_weekly` | восстановление здоровья и настроение раз в неделю |
| `ap_week` | +N ОД в неделю (редкие импланты, потолок +1) |
| `salary_pct.<карьера или all>` | +N% зарплаты |
| `gig_pay_pct`, `crime_reward_pct` | +N% оплаты заказов и добычи с криминала |
| `shop_discount_pct`, `ripper_discount_pct` | скидки в магазинах и у рипперов (потолок 50%) |
| `relation_gain` | +N к росту отношений от позитивных действий |
| `heat_decay` | розыск спадает быстрее на N в неделю |
| `humanity_loss_pct` | −N% потери человечности от будущих имплантов (стабилизаторы) |
| `therapy_bonus` | +N человечности за терапию |
| `glitch_max` | +N к максимуму глюков |
| `ram_max`, `ram_recharge`, `quickhack_cost`, `quickhack_targets` | кибердека и быстрые взломы |
| `ice` | защита от взломов вражеских нетраннеров |
| `enemy_scan` | в бою видны импланты и заряд врагов |
| `active.<группа или all>.<поле>` | правка активных имплантов: `min_charge`, `recharge_per_tick`, `recharge_on_kill`, `recharge_on_takedown`, `duration_ticks`, `cost` |

**Импланты-усилители** — отдельный класс. Они ничего не делают сами, а меняют другие импланты: охладитель позвоночника (`active.sandevistan.recharge_per_tick: 5`), конденсатор (`active.all.min_charge: -10`), синаптический ускоритель (`active.all.duration_ticks: 1`), адреналиновый насос (`active.berserk.recharge_on_kill: 10`). Именно они превращают набор хрома в билд.

**Небоевые билды.** Половина каталога работает вне боя: импланты для карьеры, торговли, учёбы, отношений, криминала и выживания. Примеры: нейрокопроцессор корпората (`xp.all`, `salary_pct.corpo`), вокальный синтезатор рокербоя (`salary_pct.rockerboy`, `mood_weekly`), записывающая оптика медиа (`salary_pct.media`, `check.gig_quiet`), механические пальцы техника (`skill.tech`, `salary_pct.mechanic`), фармакологический дозатор медтеха (`hp_regen`, `therapy_bonus`), голосовой модулятор фиксера (`check.gig_talk`, `relation_gain`), подкожный тайник (`crime_reward_pct`, `check.crime`), регулятор сна (`ap_week: 1`, `mood_weekly: -3`), нейростабилизатор (`humanity_loss_pct: -20`). Цель: под каждую роль и карьеру есть ветка развития, которая не про стрельбу.

**Принцип «дорогое — гибкое»** действует и для небоевых имплантов: дешёвые дают узкий бонус с побочкой, дорогие — шире и чище.

### Кибердека и быстрые взломы
- Кибердека даёт **RAM**: пул очков, `ram_max` и подзарядку `ram_recharge` за тик. Дорогие деки — больше RAM, быстрее подзарядка, бонус к взломам.
- **Быстрые взломы** (`quickhacks.yaml`) — программы, купленные в «Софте» у фиксера-нетраннера или у риппера. Каждый стоит RAM и требует проверки ИНТ + Нетраннинг против СЛ цели. Эффекты: урон, оглушение на N тиков, штраф к атаке, **слив заряда** имплантов цели, **отключение** импланта на N тиков, распространение на соседнюю цель.
- Взлом — обычное действие тика. Вражеские нетраннеры делают то же самое с игроком, защита игрока — Нетраннинг + `ice`.
- Вне боя дека и навык работают в заказах с подходом «взлом».

## 9a. Время, эпохи и история
**Игра идёт сквозь историю мира Cyberpunk.** Старт — эпоха, когда коммерческий хром только появляется (по умолчанию 2013, настраивается). Время идёт, появляются новые импланты и технологии, меняются банды, корпорации и районы, случаются канонные события. Династии игроков проходят через десятилетия, каждая в своём темпе: дед застал первые импланты, внук живёт в 2077.

**Личное время (решение владельца).** Как в BitLife, каждый живёт в своём темпе: ограничений на число недель в сутки нет, общих мировых часов нет. У каждого рода своя дата: новый игрок начинает в `world.start_year` (2013), наследник продолжает с даты смерти предка. Год персонажа определяет всё, что зависит от времени: доступные импланты, банды, районы, фиксеры, эпоху и цены, канонные события. Канонные события срабатывают лично, когда персонаж доходит до их даты: экран в окне и короткий пост в ленте («Нгози дожил до 2023: удар по Arasaka Tower»). Эффекты мировых событий для персонажа — это все события с датой не позже его даты. Будущее после канона общее: событие на год Y пишет Claude, когда первый персонаж доходит до Y, и все, кто дойдёт позже, получают то же самое. Ежедневки, мини-игры, ночные новости о поступках игроков и крипта по-прежнему живут в реальном времени и общие для группы.

**Эпохи** (`eras.yaml`): название, годы, краткое описание для Claude и для игрока, множители цен на хром, доступные роли, тон новостей. Ориентиры: ранний хром, корпоративные войны, Четвёртая корпоративная война и ядерный удар по Арасака-тауэр, DataKrash и падение Старой Сети, Время Красного, восстановление, Объединительная война, 2077.

**Доступность по времени.** У имплантов, взломов, оружия, районов, банд, фиксеров, рипперов, корпораций, ролей и происхождений есть `available_from` и `available_until` (годы). В 2013 нет Сандевистана «Апогей» и нет Догтауна, Maelstrom и Moxes появляются позже. Ранние импланты грубее: выше цена и потеря человечности (множители эпохи).

**Канонные события** (`timeline.yaml`): год, неделя, название, описание, эффекты из меню (ниже), текст объявления. Когда мир доходит до события, оно срабатывает: пост в ленте, эффекты применяются, Claude получает его как контекст для новостей.

**Claude пишет историю:**
- **между канонными событиями** — ежедневные новости в духе эпохи, мелкие местные события с небольшими эффектами;
- **после канона** (когда закончились события `timeline.yaml`) — Claude сам пишет будущее: раз в `world.future_beat_weeks` недель (по умолчанию 26) генерирует крупное событие по JSON-схеме с эффектами из меню. Код проверяет схему и коридоры, событие попадает в `world_history`. Админ видит его в `/admin_history` и может отменить в течение суток;
- Claude всегда получает сжатую историю мира (канон + сгенерированное + легенды игроков), чтобы будущее не противоречило прошлому. Поступки игроков становятся частью истории: легендарные заказы, громкие смерти, династии.

**Меню эффектов мировых событий** (с коридорами в `balance.yaml`): изменение цен по категории, опасность района, война банд, сила фракции, открыть или запретить предмет (запрещённый хром у риппера даёт розыск), множитель розыска, множитель оплаты заказов, вес категорий событий, открыть или закрыть район, смена эпохи.

## 10. Отношения (BitLife)

- При создании генерируется семья: родители (живы или нет, где живут, отношение), 0–3 брата и сестры.
- Каждый NPC: имя, роль, отношение 0–100, флаги (должен денег, враг, в беде).
- Действия, 1 ОД: провести время, попросить денег, поссориться, подарок, познакомить, разорвать.
- Партнёр: знакомство в баре или через события. Можно съехаться (общая аренда), потом могут появиться дети.
- **Протеже**: молодого NPC можно взять в ученики (Активности). Он может стать наследником.
- **Контакты**: фиксеры и рипперы тоже NPC с отношением, высокое отношение снижает цены.

## 11. Работа, деньги, криминал

### Экономика (эдди в неделю)
| Жильё | Аренда |
|---|---|
| Капсула в Кабуки | 100 |
| Комната в мегабашне H10 | 250 |

Еда 50–150 в зависимости от жилья. На старте 500 эдди плюс стартовый долг.

### Долг
- Ставка 0,75% в неделю (`balance.debt.weekly_rate`), проценты начисляются до платежа.
- Минимальный платёж: 2% долга, но не меньше 100 эдди (или весь остаток). Списывается сам при «Прожить неделю», если эдди хватает на весь минимум; иначе неделя считается пропущенной.
- Две пропущенные недели подряд — событие коллектора; долго не платить опасно (`balance.death.collector_kill_weeks`). Оплата или договор с коллектором в событии списывает пропуски.
- Эдди ниже нуля превращаются в долг («Долг по счетам»), и экран исхода это показывает.
- Проверка симуляцией: долг 3 000 / 5 500 / 8 000 при зарплате 350–800 гасится одними минимумами за 35 / 71 / 100 недель, на остальное персонаж тратит деньги свободно.
- Долги, сохранённые при старой модели (5% в неделю), при запуске переводятся на новую ставку, а начисленные проценты пересчитываются по ней (`services/debtfix.py`, один раз).

### Отчёт недели
Денежный блок показывает зарплату, аренду, еду, Trauma Team, проценты и платежи по долгу, деньги событий с прошлого отчёта, отложенные итоги, которые пришли на этой неделе, и итог «за неделю: ±N эдди, на счету M». Ни одно движение эдди не проходит молча.

### Легальные карьеры (5 ступеней, повышение через недели стажа и проверки)
- **Корпорат** (Arasaka, Militech, Kang Tao, Biotechnica): стажёр → младший → менеджер → старший → директор. События: подставы, переманивание, тайные задания.
- **NCPD**: патрульный → детектив → MaxTac (нужны импланты не меньше чем на 20 ПЧ).
- **Trauma Team**: медтех или стрелок.
- **Медиа**: журналист N54.
- **Рокербой**: выступления в барах, фанаты, контракт.
- **Механик / техник**.

Зарплата идёт раз в неделю. Действие «Работать усерднее» повышает шанс повышения. Если на работе узнают о криминале — событие с риском увольнения.

### Заказы (гиги)
- Фиксер своего района предлагает 3 заказа. Доска личная: у каждого игрока своя, она обновляется раз в `gigs.board_refresh_weeks` недель личного времени.
- Типы: доставка, кража, устранение, взлом, охрана, охота на киберпсиха, поиск пропавшего.
- Уровни 1–5, открываются уличной репутацией (0 / 5 / 15 / 25 / 35).
- Контракты 6–9 (запрос 29.10): открываются репутацией 44–50 и рангом контрактов (очки за удачные заказы, без потолка), сложность 23–29, оплата от десятков тысяч до сотен тысяч, залог 10%. Подробности: `docs/PLAN_GIGS_ELITE.md`.
- Оплата: ур.1 300–600, ур.2 800–1 500, ур.3 2 000–4 000, ур.4 5 000–9 000, ур.5 12 000–25 000.
- Игрок выбирает **подход**: громко, тихо, договориться, взлом или своё действие свободным текстом. Подход определяет, какие навыки проверяются (2–3 проверки).
- Исход на 4 уровня (раздел 6) определяет оплату (100 / 60 / 0 / 0%), урон, розыск, репутацию и отношение фиксера.
- «Громко» с осложнением или провалом запускает бой.

### Криминал (BitLife)
Карманная кража, угон, ограбление магазина, нападение. Быстрые деньги, рост розыска.
Розыск 3+: шанс облавы при «Прожить неделю». Розыск 5: охота MaxTac.
Арест → **тюрьма** на 4–52 недели. В тюрьме доступны только тренировка, драка, связи и побег (проверка). Недели в тюрьме идут быстрее (одно нажатие = 4 недели).

## 12. Случайные события

- При «Прожить неделю» выпадает 1–3 события. Вес зависит от района, роли, статов, розыска, человечности и долга.
- Каждое событие — шаблон в YAML: условия, текст-заготовка, 2–3 варианта выбора, у каждого варианта проверка и эффекты.
- **Обещание = механика.** Если исход обещает имплант, вещь, контакт, работу, скидку или деньги потом, эффекты это дают: имплант ставится (`cyberware_grant`), вещь кладётся в инвентарь (`item_grant`), контакт появляется (`add_npc`), работа начинается (`career_set`), а отложенные деньги приходят через **отложенный исход** (`later`): через N недель неделя бросает шанс, и итог («Кафе в Кабуки: первая выручка», «Кафе прогорело») показывается блоком в отчёте недели. Вложения — настоящая ставка: часть окупается с плюсом, часть сгорает.
- Экран исхода показывает все изменения ресурсов строками: эдди, долг (и сколько ушло в долг, если эдди не хватило), новый имплант, вещь, работа, отложенный итог «через 4 недели».
- Стартовый набор — 40 событий. Например: засада мусорщиков, дешёвый хром у подпольного риппера, звонок бывшей, родственнику нужны деньги, проверка документов NCPD, зависимость от брейнданса, сосед стал киберпсихом, хедхантер Arasaka, коллектор по долгу, приглашение в Afterlife, драка в баре, найденный осколок с данными.
- **Уникальное событие от Claude**: раз в неделю на игрока Claude может сгенерировать событие по JSON-схеме. Эффекты ограничены коридором (деньги ±20%, здоровье ±15 и так далее). Код проверяет схему и коридоры и при ошибке берёт шаблон.

## 12a. Ежедневки и удержание
Telegram-игры живут на ежедневной привычке. У игры есть короткий ежедневный цикл, который занимает минуту, и длинные цели поверх него.

- **Ежедневка** (`/daily` или кнопка в меню), раз в сутки по Киеву: **карта Мисти** — одна из 22 карт Старших арканов, баф или дебаф на сутки в виде временных модификаторов (раздел 8), плюс эдди. Награда растёт с **серией** дней подряд: 7 дней — сундук, 30 дней — редкая награда. Пропуск сжигает серию, если нет «заморозки».
- **Ежедневные задания**: 3 в сутки из пула, подобранные под путь игрока (боевые, небоевые, без хрома), плюс одно недельное. Примеры: «сделай заказ тихо», «проведи время с семьёй», «отработай неделю без опозданий», «не попадись NCPD», «помедитируй». Награды: эдди, опыт, репутации, **жетоны Afterlife**.
- **Жетоны Afterlife** — мета-валюта. Тратятся у бармена Afterlife на бусты: стим (+2 к одной проверке), полная зарядка имплантов, заморозка серии, переброс карты Мисти, косметические титулы. Нельзя купить за эдди и нельзя передать.
- **Мемные мини-игры** — по минуте в день, привязаны к игроку и переживают смерти персонажей:
  - **Калибр** (`/caliber`, `/caliber_top`): раз в сутки калибр твоего ствола растёт или усыхает на случайное число миллиметров, топ группы, титулы на рубежах.
  - **Тачка** (`/car`, `/race @игрок`): раз в сутки тюнинг — лошадиные силы растут или падают, иногда отваливается деталь. Гонка с другим игроком на ставку жетонов: мощность + бросок, одна гонка на пару в сутки.
  - **Кибер-кот** (`/cat`, `/catfight @игрок`): кормишь кота раз в сутки, он растёт по уровням. Не кормил 2 дня — обижается, 7 дней — уходит к соседу (возвращается за жетоны). Хром для кота покупается за жетоны: когти, оптика, хвост. Кошачий бой с котом другого игрока раз в сутки.
  - **Эдди-крипта** (`/coin`): у группы общий курс монеты, раз в сутки он случайно гуляет, мировые события и канон устраивают обвалы и взлёты. Покупаешь за эдди персонажа, монеты лежат в кошельке игрока и переживают смерть («офшор»), продаёшь в эдди текущего персонажа с комиссией 10%. Топ капиталов.
- **Компромат** (`/dirt`): раз в сутки копится d3 компромата на город. Накопил 5 — `/dump @игрок`: сливаешь наводку в NCPD, у персонажа цели розыск +1 и публичный пост. Цель может отбиться проверкой ХЛАД или связями с фиксером, тогда компромат возвращается тебе бумерангом. Ограничение: на одного игрока не чаще раза в 3 дня.
- **Напоминания в группе**: в 12:00 короткий пост «Ежедневка обновилась» (удаляется через 3 часа), в 21:00 упоминание тех, у кого сгорает серия. Раз в неделю пост «Легенды недели»: кто больше всех вырос по каждой репутации, лучший калибр, громкий слив компромата.
- Всё ежедневное работает и для мёртвых: если персонаж умер, ежедневка начисляет жетоны и серию игроку, а карта Мисти ждёт следующего персонажа.

## 13. Смерть и наследие

### Причины смерти
Бой, киберпсихоз (убит при эпизоде или на охоте), тюрьма, коллектор, передоз брейндансом, отказ импланта, старость (после 70 лет шанс растёт каждый год).

### После смерти
1. Claude пишет некролог, он уходит в общую беседу.
2. Запись на кладбище: имя, годы жизни, роль, причина смерти, итоговая репутация, главное достижение.
3. Игрок выбирает, как продолжить:

| Вариант | Условие | Что переходит |
|---|---|---|
| **Ребёнок или родственник** | есть живой | 50% денег, жильё, 25% долга, отношения семьи, 30% репутации, враги из банд |
| **Протеже** | есть протеже | связи с фиксерами (отношение), 20% репутации, 1 навык на уровне −2 |
| **Энграмма** | была оплачена «Secure Your Soul» (Arasaka, 25 000 эдди) | 50% навыков, человечность −20, событие «конфликт личности» раз в 10 недель |
| **С нуля** | всегда | ничего, но +1 к максимуму глюков за каждую прошлую жизнь в роду (максимум +2) |

### Род
- У каждого игрока есть **род** — цепочка жизней. `/lineage` показывает историю.
- NPC и фиксеры знают фамилию рода. В контекст Claude передаётся короткая сводка о прошлых жизнях, поэтому Регина может сказать: «Твой отец тоже начинал с доставок».

## 14. Роль Claude

### Что пишет Claude
- брифинги заказов голосом фиксера;
- исход заказа или события по структурированному результату;
- тексты случайных событий (переписывает шаблон с учётом персонажа);
- уникальные события по JSON-схеме (раздел 12);
- некрологи и ночные новости;
- короткие разговоры с NPC свободным текстом (до 6 реплик за разговор);
- разбор свободного действия: переводит текст игрока в подход и навык по JSON-схеме.

### Что Claude не решает никогда
Числа, исходы проверок, смерть, награды. Эффекты уникальных событий проходят коридоры кода.

### Модели и бюджет
- `claude-sonnet-5-5` — нарратив: брифинги, исходы, события, некрологи, новости, разговоры.
- `claude-haiku-5-5` — разбор свободного ввода и короткие реплики.
- Кэширование промпта для лор-блока (мир, тон, словарь), он одинаков для всех вызовов.
- Месячный лимит в Console плюс внутренний счётчик расходов (`llm_usage`). При 90% бюджета бот переходит на шаблонные тексты и пишет администратору.
- Любая ошибка API → шаблонный текст. Игра не останавливается из-за Claude.

### Тон
Нуар CY_BORG плюс уличный язык Найт-Сити. Коротко, жёстко, с чёрным юмором. Не больше 600 знаков на обычное сообщение, некролог до 900.

### Контракт результата (пример)
```json
{
  "kind": "gig_result",
  "character": {"name": "Ксения Ли", "role": "Нетраннер", "district": "Уотсон", "lineage_note": "дочь Марка Ли, погиб в 2077"},
  "fixer": "Регина Джонс",
  "gig": {"type": "взлом", "title": "Данные Kang Tao", "tier": 2, "approach": "тихо"},
  "checks": [{"skill": "Скрытность", "dv": 15, "total": 17, "ok": true}, {"skill": "Нетраннинг", "dv": 15, "total": 12, "ok": false}],
  "outcome": "complication",
  "effects": {"eddies": 720, "hp": -6, "heat": 1, "street_cred": 1, "fixer_rel": -5}
}
```
Claude описывает ровно то, что в объекте, и не добавляет новых последствий.

## 15. Картинки

- **v1** — заранее сгенерированная библиотека (около 30 картинок, сделаны вручную в ChatGPT). Манифест `images/manifest.yaml`: файл и теги (район, тип события, смерть и так далее). Бот подбирает картинку по тегам, а если подходящей нет — шлёт без неё. После первой отправки бот запоминает Telegram `file_id` и не загружает файл повторно.
- **v2** — генерация через OpenAI Images API для уникальных моментов (портрет в некрологе, легендарный заказ) с кэшем. API оплачивается отдельно, в подписку ChatGPT Plus не входит.

## 16. Админ-команды (для тестирования)
`/admin_give <user> <eddies>`, `/admin_grant_cyber <user> <имплант>` и `/admin_grant_item <user> <оружие или броня>` (бесплатная выдача, компенсация за сломанное событие), `/admin_kill <user>`, `/admin_set <user> <field> <value>`, `/admin_tick` (запустить суточный тик реального времени), `/admin_year [@user]` (личная дата игрока), `/admin_history`, `/admin_veto <id>`, `/admin_event <user> <event_id>`, `/admin_budget`. Доступны только Telegram ID из `ADMIN_IDS`.

## 17. Дальше (v2+)
Совместные заказы на 2–4 игроков, игроки нанимают друг друга, полноценное PvP, контроль районов, свой бизнес (бар, клиника), генерация картинок на лету, сезонные городские сюжеты.
