# PLAN_ARCADE.md — популярные HTML5-игры в боте (запрос 29.10)

Владелец: «найди топ популярных html5 игр и давай внедрим их» и скриншот поисковой выдачи «Top Popular HTML5 Games»:
Townscaper, Slither.io, Wordle, GeoGuessr, Hextris, Moto X3M, Gartic Phone, Friday Night Funkin'.

Что из списка ложится на кнопки Telegram (одно окно, ход по нажатию), а что нет:

| Игра | Решение |
|---|---|
| Wordle | «Взлом пароля»: слово дня из пяти букв, шесть попыток, цветные плитки |
| Slither.io | «Змейка»: поле 8×8, четыре стрелки, ход на нажатие, рекорд длины |
| GeoGuessr | «Угадай район»: подсказки по районам Найт-Сити (места, банды, фиксер), пять раундов |
| Friday Night Funkin' | «Рэп-баттл»: последовательность стрелок растёт, повтори её кнопками (как Simon) |
| Townscaper | «Застройка»: поле 6×6, нажатие меняет здание, свой городок на экране |
| Hextris, Moto X3M | не делаем: нужна анимация в реальном времени, кнопки Telegram её не дают (гонки уже есть в «Машине») |
| Gartic Phone | вторая очередь: цепочка «Сломанный телефон» между игроками (письма), нужна отдельная механика |

Вход: «Город» → «🕹 Аркада». Окно игрока одно, все игры редактируют его.

Правила
1. Состояние игры лежит в `world_state` ключом `arcade:<tg_id>` (код без миграций таблиц): игра переживает закрытое окно.
2. Награда в эдди только персонажу, с дневным потолком `balance.arcade.daily_cap` на игрока по киевским суткам (в игре
   у верхних игроков миллионы, поэтому деньги символические, главное рекорды). Строка «Аркада на сегодня: N из M».
3. Рекорды по играм в `world_state` `arcade:top`; экран «Рекорды» показывает тройку лучших и свой результат.
4. Wordle: слово дня общее для всех (по киевской дате), список слов в `balance.arcade.wordle.words` (пять букв, проверка
   загрузчиком), угадывание любой пятибуквенной кириллической строки. Одна игра в сутки на игрока. Награда по числу
   попыток.
5. Змейка: рекорд длины; награда `snake.eddies_per_food` за еду.
6. Угадай район: раунд из `rounds` вопросов, до трёх подсказок; очки 3/2/1; награда `geo.eddies_per_point`.
7. Рэп-баттл: раунд добавляет стрелку; награда `beat.eddies_per_round` с четвёртого раунда; рекорд длины цепочки.
8. Застройка: без награды, рекорд по числу зданий.

Код: `app/engine/arcade.py` (чистые правила), `app/services/arcade.py` (состояние, награды, рекорды),
`app/bot/handlers/arcade.py` (экраны), кнопка в `handlers/city.py`, `balance.arcade`, `schemas.ArcadeBalance`.
Ручные проверки: `docs/TEST_CASES.md`, раздел «Аркада».
