# PLAN_CHROME_FX.md — эффекты хрома на экране (запрос 30.10)

Владелец: «тематические эффекты при использовании способностей имплантов, включении Сандевистана, Берсерка; большая надпись
выскакивает и отдаляется, становясь прозрачной. Типа САНДЕВИСТАН». Только Mini App; группа без изменений.

## Как работает

1. `app/bot/combat_fx.py::recent` читает события боя игрока за прошлый и текущий ход: включение импланта (`activate`),
   выстрел имплантом (`shot`), уворот имплантом (`dodge` с `imp`). Для способности хрома (`cmab use`) запись добавляет
   обработчик. Запись: `{id, kind, word}`; `id` = `тик:номер события` (стабилен, приложение играет его один раз).
2. `handlers/combat.py::_with_fx` кладёт список в `screen.state["fx"]`, `app/webapp/render.py` отдаёт его как `screen.fx`.
3. `webapp/app.js` (блок «chrome on the screen»): эффект играет только ответ на нажатие самого игрока; при загрузке и по
   потоку событий уже показанные id запоминаются без проигрыша. Вне боевых экранов память id сбрасывается.
4. Вид (`kind`): по группе импланта (sandevistan, berserk, kerenzikov), затем по кнопке, у способностей по семейству.
   - sandy (Сандевистан, Горизонт, спринт): зелёно-циановый сдвиг цвета экрана, полосы скорости, цветные остаточные
     изображения надписи;
   - berserk (Берсерк, Штурм, клинки, сила): красная пульсирующая виньетка, тряска, дрожащая надпись, тройная вибрация;
   - kerenzikov (Керензиков, Уклон, предвидение): янтарная вспышка и кольцо;
   - cloak (Маскировка, Мираж, Фаза): мерцание и размытие экрана, полосы помех;
   - smoke, blast (ракеты, граната, рука-пушка: вспышка, ударная волна, тряска), swarm (нанорой), stim, emp, chrome
     (остальное: сканирующая полоса).
   Надпись — слово кнопки импланта или имя способности заглавными, размер под ширину экрана; влетает крупной и за
   ~1,9 с уходит вдаль, уменьшаясь и растворяясь.
5. Цветокод (запрос 30.10 «литания розовая, чёрный для Чёрного Заслона»): квикхаки игрока тоже играют эффект (успешные,
   один раз на программу за ход), удар оружием Заслона тоже («ЧЁРНЫЙ ЗАСЛОН»).
   - blackwall, чёрный: всё культовое — скрипты `bw_*`, импланты сборки `blackwall`, их способности, оружие Заслона. Экран
     проваливается в черноту с инверсией, рваные чёрные полосы с красной кромкой, надпись — чёрная дыра с красным краем;
   - litany, розовый: «Литания» (имплант `bw_litany`, способность `litany_voice`, скрипт «Гимн помех»), розовые кольца;
   - fire, оранжевый (Перегрев, Автомат, Синаптический ожог): искры снизу;
   - shock, голубой (Короткое замыкание, Цепная молния, Перегрузка, Нейрошторм, Системный сбой): разряды;
   - jam, фиолетовый (Перезагрузка оптики, Отвлечение, Глушилка, Погасить свет, Звуковой шок): помехи, RGB-сдвиг;
   - virus, ядовито-зелёный (Заражение, Пиявка, Слив заряда): расползающиеся точки;
   - glitch, жёлтый (Сбой оружия, Обездвиживание, Сбой импланта): рваные полосы, дрожь.
   Длинные названия из двух слов переносятся на две строки.
6. При «уменьшении движения» в системе остаётся только надпись.
