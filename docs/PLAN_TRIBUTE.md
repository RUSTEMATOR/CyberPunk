# PLAN_TRIBUTE.md — дань с людей города (запрос 27.10)

Владелец (скриншот: свой вариант «два миллиона эдди в месяц за спокойствие башни» Юки Мори разобран как «Подкупить»,
персонаж заплатил 300): «Чего блядь. Они должны мне платить».

Причина: у разбора своего варианта не было действия «требовать денег», и упоминание денег уводило в `bribe`.

1. Новое действие с жителем: «Обложить данью» (`extort`), кнопкой и своим вариантом. ХЛАД + Убеждение против
   сложности жителя +2, 1 ОД. Успех: житель отдаёт половину того, что при себе, и **платит дань каждый прожитый месяц**.
   Провал: отношение хуже, вооружённый начинает драку.
2. Размер дани: `freedom.tribute.base` по типу жителя (корпорат, мажор, лейтенант банды платят больше, бездомный —
   почти ничего), × (1 + уличная репутация / `per_cred`) × (1 + слава / `per_fame`), не больше `cap`. Платящих не больше
   `max_payers` (новый вытесняет самого старого). Каждый месяц шанс `stop_chance`, что житель перестанет платить
   (сообщение: напомни ему). Мёртвый житель не платит.
3. В карточке жителя строка «Платит тебе дань: N эдди в месяц». В итогах месяца — «Дань: +N эдди (кто)».
4. Разбор своего варианта: `bribe` — только когда персонаж сам платит жителю; требование денег с жителя (дань, плата
   за защиту, рэкет, «ты мне должен») — `extort`. Сцена исхода не берёт суммы из текста игрока: что реально перешло,
   видно только по effects.
5. Кэрол возвращаются 300 эдди за неверно разобранный свой вариант (разово, письмом).

Код: `content/balance.yaml` (`freedom.verbs` + `freedom.tribute`), `schemas.FreedomBalance.tribute`,
`app/services/city.py` (`do`: дань при успехе, `tribute_hook`), `app/services/week.py` (вызов хука),
`app/bot/handlers/city.py` (строка в карточке), `app/bot/texts_city.py`, `app/narrator/prompts.py`.
